مدونة أدبية بتصميم فاخر لنشر الخواطر والإيمانيات كصور جاهزة للإنستغرام.

## المميزات
- 📖 تصفح الخواطر بتصميم فاخر (1080×1350 مثالي لإنستغرام)
- 🎨 4 قوالب: الورق الفاخر، الليل المخملي، النور، الأصالة
- ✍️ تحكم مطلق في نوع وحجم الخط (Amiri, Cairo, Tajawal, Lateef, Scheherazade, Reem Kufi)
- 🖋️ توقيع بخط A Arslan Wessam B - خط يد حر حقيقي
- 🔒 وضع الإدارة: أنت فقط تضيف/تعدل، والزوار يتصفحون ويشاركون فقط

## كيف ترفع على GitHub Pages

### 1. أنشئ Repository جديد
- اذهب إلى https://github.com/new
- اسم المستودع: `raheeq` 
- اختر Public
- لا تضف README

### 2. ارفع الملفات
افتح Terminal في مجلد المشروع واكتب:

```bash
git init
git add .
git commit -m "إطلاق رحيق الحروف"
git branch -M main
git remote add origin https://github.com/USERNAME/raheeq.git
git push -u origin main
```

استبدل USERNAME باسم حسابك على GitHub.

### 3. فعّل GitHub Pages
- اذهب إلى Settings > Pages في المستودع
- Source: Deploy from a branch
- Branch: main / root
- اضغط Save

بعد دقيقة سيظهر رابط موقعك: https://USERNAME.github.io/raheeq/
